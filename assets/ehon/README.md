# えほん挿絵アセットについて

てんてんゲームの「えほんだな」5作品(大きなかぶ／三びきのくま／ももたろう／
三びきのこぶた／赤ずきん)の表紙・本文挿絵を配置するフォルダです。

## 現在の状態

**画像ファイルはまだ1枚も配置されていません。** 各フォルダの `source.txt` に
記載した候補は、いずれも Wikimedia Commons 上でパブリックドメインと確認できた
作品ですが、この実行環境は外部ドメイン(commons.wikimedia.org /
upload.wikimedia.org 等)へのネットワークアクセスが組織ポリシーでブロックされて
おり、画像バイナリを直接ダウンロードできません。

## 画像を追加する方法

1. 各フォルダの `source.txt` に記載された「出典ページURL」を開く
2. パブリックドメインであることを確認したうえで画像をダウンロードする
3. `source.txt` に書かれたファイル名(`cover.jpg` / `page01.jpg` など)で
   そのフォルダに保存する
4. 出典・ライセンス情報が変わる場合は `source.txt` も更新する

## フォルダ構成

```
assets/ehon/
  01_大きなかぶ/     source.txt (cover.jpg 候補1件)
  02_三びきのくま/   source.txt (cover.jpg 候補1件)
  03_ももたろう/     source.txt (cover.jpg + page01.jpg 候補)
  04_三びきのこぶた/ source.txt (cover.jpg + page01.jpg + page02.jpg 候補)
  05_赤ずきん/       source.txt (cover.jpg + page01.jpg 候補)
```

候補が見つかっていないページには無理に画像を割り当てていません。権利不明の
画像を追加することはしないでください。

## コード側の対応

- `js/picture-book.js` の `coverImage` / 各ページの `image` に、上記の
  想定パスをあらかじめ設定済みです。ファイルを配置するだけで自動的に
  表示されます。
- ファイルが存在しない・読み込みに失敗した場合でもゲームはクラッシュせず、
  表紙は絵文字、本文ページは「🖼️ がぞうを じゅんびちゅうです」という
  プレースホルダー表示にフォールバックします(`js/screens.js`)。
